# Plastic Website 3

Professional B2B plastic manufacturing catalog and showcase website featuring high-grade industrial containers, storage crates, packaging, and custom injection molding capabilities.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS

## Getting started

Prerequisite: Node.js 18+

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and set your values (e.g. `GEMINI_API_KEY`).
3. Start the dev server:
   `npm run dev`

The app runs at http://localhost:3000.

## Scripts

- `npm run dev` - start the dev server
- `npm run build` - production build
- `npm run preview` - preview the production build
- `npm run lint` - type-check with TypeScript
